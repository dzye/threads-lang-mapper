Threads 中文阅读 0.1.2

- Threads 帖文与回复自动繁简转换，英语、日语、韩语等语言通过 Chrome 内置模型本地翻译。
- 可配置目标语言和来源语言范围，默认全选，支持全选、反选与原文对照。
- 自动处理滚动加载内容，译文保留超链接。
- 修复无 lang 正文漏译、翻译按钮文字混入、多行模型漏译和加载按钮重复点击问题。

安装：解压附带的 ZIP，在桌面 Chrome 的 chrome://extensions/ 中开启开发者模式并选择解压目录。该 ZIP 也可直接上传 Chrome Web Store。

验证：13 项自动测试及构建通过；已在 Chrome 实测繁简、英/日/韩首次启用、模型准备、刷新复用、滚动翻译和真实链接跳转。未清空浏览器模型缓存，不承诺零缓存下载已验收；自动翻译可能有语义误差。
