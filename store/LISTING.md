# Chrome Web Store 商店资料

名称：Threads 中文阅读

简短说明：自动将 Threads 帖文与回复转换为简体中文，支持配置目标语言及查看原文。

分类：工具（若后台提供更具体的翻译/语言类别，选择该类别）

语言：简体中文

## 详细介绍

在 Threads 阅读不同语言的内容，让时间线说你的语言。

Threads 中文阅读可自动将帖文和回复中的繁体中文转换为简体中文，并使用桌面版 Chrome 内置翻译能力翻译英语、日语、韩语等受支持语言。

主要功能：
• 自动处理当前页面及滚动新加载的文字帖文、回复。
• 繁简转换使用本地 OpenCC 词典。
• 配置目标语言；按来源语言勾选翻译范围，默认全选，支持全选和反选。
• 可保留原文与译文对照，或只显示译文。
• 保留译文内超链接；必要时提供原文链接入口。
• 设置自动保存，无需配置 API Key。

开始使用：
1. 安装后打开或刷新 Threads 网页。
2. 点击工具栏扩展图标设置目标语言和来源语言。
3. 首次使用某种外语时，按页面提示点击启用，等待 Chrome 准备对应语言模型。

使用条件与限制：
• 面向桌面 Chrome 138 及更新版本，外语翻译取决于浏览器、语言对、模型和系统策略的支持情况。
• 首次模型准备可能需要联网和用户点击；未支持的语言、低置信度内容保留原文。
• 处理网页文字，不识别图片、视频内的文字，不提供私信翻译。
• 自动翻译可能出现人名、口语及上下文误译，建议保留原文核对。
• Threads 页面结构更新可能需要适配。

隐私：帖文翻译在设备本地完成，没有自有服务器、广告或遥测。Chrome 可联网下载语言模型；Chrome 同步可同步语言与显示设置，扩展不会同步帖文与译文。

本扩展是独立工具，不隶属于 Meta、Threads 或 Google。

源码与支持：https://github.com/dzye/threads-lang-mapper
隐私政策：https://github.com/dzye/threads-lang-mapper/blob/main/PRIVACY.md

## 单一用途

在 Threads 网页中，根据用户选择的来源语言与目标语言，自动翻译帖文及回复文字并进行中文繁简转换。

## 权限用途说明

storage：保存并按 Chrome 同步配置同步自动翻译开关、目标/来源语言和双语显示偏好。不存储或同步帖文、译文。

Threads 站点内容脚本访问：读取当前 Threads 页面可识别的帖文与回复文字、语言信息及超链接，在对应位置显示本地处理的译文。声明范围限定为 Threads 的四个 HTTPS 域名。

远程代码：不使用远程代码。可执行 JavaScript、OpenCC 词典和样式全部随扩展打包；Chrome 内置 API 的语言模型下载由 Chrome 管理，扩展不下载或执行远程 JavaScript。

数据处理：披露网页内容在本地用于翻译。不要将“没有服务器”误填为“完全不处理网页内容”。按后台当时的字段定义填写，并与 PRIVACY.md 保持一致。

## 审核测试步骤

1. 使用支持 Translator API 的桌面 Chrome 138+。
2. 打开 Threads（如站点要求，请使用审核人员自己的测试账号；扩展不提供或要求额外账号）。
3. 查看包含繁体中文的帖文及回复，确认简体译文；下滚查看新增内容。
4. 点击扩展图标，反选来源语言后应恢复原文，全选后恢复翻译。
5. 查看英语、日语、韩语帖文。若模型尚未就绪，点击页面右下角启用对应语言，等待模型准备完成。
6. 查看带超链接的译文，链接应继续打开原目标。

本地自动化测试：npm ci && npm run check。
