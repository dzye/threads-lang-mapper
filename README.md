# Threads 中文阅读

Chrome Manifest V3 扩展。默认将 Threads 帖文、回复中的繁体中文自动转换为简体中文；其他语言使用 Chrome 内置 Translator API。目标语言可在扩展弹窗配置。

## 安装使用

1. 使用桌面版 Chrome 138 或更新版本。打开 `chrome://extensions/`。
2. 开启右上角「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择本项目的 **dist 文件夹**（不要选择项目根目录）。
4. 打开或刷新 `https://www.threads.com/`，繁体中文会自动转换。旧的 threads.net 域名也在支持范围内。
5. 点击浏览器工具栏的扩展图标，设置目标语言、自动翻译、双语显示和外语翻译开关。在“需要翻译的语言”列表选择来源语言，默认全选，可全选或反选；取消勾选后保留该语言原文，已显示的对应译文也会撤下。已有旧设置在首次更新时默认全选。
6. 若遇到外语模型尚未就绪，页面右下角会出现「启用」按钮；点击下载对应模型，完成后继续自动处理。加载失败会保留原文并提示错误。

默认保留原文，在下面显示译文。关闭「保留原文」会隐藏原文字块，但不会改写原文内部 DOM；关闭「自动翻译」恢复原文。更新扩展后需要重新加载扩展并刷新 Threads。

## 能力与边界

- OpenCC 本地词典处理繁简转换，无需登录翻译服务或 API Key。
- Chrome 内置翻译本地处理文本；首次语言模型下载需要网络及用户点击。支持情况受 Chrome 版本、策略、语言对和页面权限策略影响。
- 目标语言包括简体、繁体、英语、日语、韩语、法语、德语、西班牙语等 14 种。下拉选项不代表当前浏览器支持全部语言对，不支持时保留原文并提示。
- 自动监听新帖文、回复、滚动加载及站内节点复用，仅处理视口附近的文字。最多缓存 500 条外语译文，仅保存在当前页面内存。
- 保护导航、按钮、账号链接、输入框与编辑区；跳过 direct/inbox/messages/chat 页面路径。不识别图片、视频中的文字。
- 繁简转换属于文字转换，不等于台湾用语全部改写为大陆用语；多义字与上下文仍可能有误。外语检测对短句、混合语言也可能误判或跳过。
- Threads 没有提供稳定的正文 DOM 接口。本版本使用语义选择器匹配，实际站点结构变动可能导致遗漏，需调整 `src/dom.js`。2026-10-25 已在用户已登录的桌面 Chrome 实测帖文详情、回复滚动加载与首页信息流；站点后续更新仍需回归。
- 没有使用非官方 Google Translate 网络接口，也没有配置云翻译服务。

## 开发

```sh
npm ci
npm run check
```

构建结果输出至 `dist/`，Chrome 可直接加载。所有脚本与词典随包提供，没有远程脚本。

测试覆盖：繁简转换、语言与设置校验、模型初始化及缓存、正文筛选与 HTML 注入保护、动态新增、节点复用、隐藏原文及停用恢复。DOM 测试使用 jsdom；已完成 Threads 实站繁简转换与滚动测试。2026-10-25 已验证英/日/韩三种语言的首次启用、模型准备完成、刷新复用与滚动自动翻译。未清空 Chrome 系统模型缓存或抓取下载流量，不能据此断言从零缓存完成了完整网络下载。原生模型仍存在语义误译，逐行调用避免多行整体请求漏译。

译文中的 HTTP(S) 网址、原文超链接和提及可继续点击；若译文改写了链接文字，则在“原文链接”区域保留原始地址。

扩展仅申请 `storage` 权限，以及四个 Threads HTTPS 域名的声明式内容脚本访问范围。Chrome storage.sync 同步设置；不保存或同步帖文、译文。无遥测及自有服务器。
